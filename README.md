## 📖 About The Project

**India Fitness** is the premier fitness destination and high-performance training gym in **Sipara, Kurthaul, and Sampatchak (Patna, Bihar)**. This digital portal provides gym members, athletes, and fitness enthusiasts with a cutting-edge web experience tailored for strength training, body transformation, nutrition tracking, and membership onboarding.

Built with a modern ultra-dark design system inspired by top global fitness interfaces, the portal merges high-conversion architecture with rich interactive fitness utilities.

## ✨ Key Features & Capabilities

### 1. 🎨 FitFlex High-Performance Aesthetic
- Signature chartreuse/neon lime accent palette (`#f2fd84`).
- Gritty high-contrast athlete imagery with hollow-stroked outline typography (`ACHIEVE MORE THAN JUST FITNESS`).
- Floating frosted-glass statistics showcase with live dynamic metrics (1,500+ Happy Members, 50+ Modern Equipment bays, 3 Certified Trainers, 99% Transformation Rate).

### 2. 📱 Global Off-Canvas Side Drawer Navigation
- Responsive off-canvas slide-out drawer accessible on desktop, tablet, and mobile.
- Dedicated quick-access close buttons, backdrop blur, and escape key listener.
- **Dynamic Workout Plan Summary Widget**: Automatically syncs in real-time with `localStorage` to display the member's active 7-day workout routine directly inside the navigation drawer.

### 3. 🤖 Interactive Workout Plan Generator
- Custom 7-day routine builder based on fitness goals (Muscle Gain, Fat Loss, Strength & Power, Lean Athletic).
- Tailors exercise sets, reps, and muscle split groups (Chest, Back, Legs, Shoulders, Arms, Core) according to gym or home equipment availability.
- Dynamic Diet Plan & Macro-Nutrition calculator integrated directly into workout recommendations.

### 4. ⚖️ Clinical BMI Health Assessment Calculator
- Real-time Body Mass Index calculation with category classification (Underweight, Normal, Overweight, Obese).
- Metabolic guidance and direct WhatsApp consultation routing for customized coaching.

### 5. 🛡️ Content Management & Lead Security
- **Decap CMS (`/admin`)**: Git-backed headless CMS configuration (`admin/config.yml`) allowing non-technical managers to update membership packages, trainer profiles, and gym galleries directly in `_data/`.
- **Hardened Bot Protection**: Honeypot anti-spam fields on all contact forms.
- **Direct Lead Automation**: Form routing via Web3Forms and one-tap WhatsApp integration (`+91 8544007735`).

## 🛠️ Technology Stack & Architecture

- **Frontend Core**: Semantic HTML5, CSS3 Custom Properties (Modern CSS Grid & Flexbox), Vanilla JavaScript (ES6+ Modules).
- **Design System**: FitFlex Theme System (`fitflex-theme.css`, `style.css`).
- **Interactive Libraries**: Leaflet.js (Interactive Geolocation Map), AOS (Animate on Scroll), FontAwesome 6.
- **State & Data**: Decap CMS, GitHub OAuth, JSON-based content repository (`_data/*.json`).
- **Deployment & Edge Infrastructure**: Vercel Serverless Hosting, Security Headers (`CSP`, `HSTS`, `X-Content-Type-Options`), Web App Manifest, Schema.org Local Business Structured Data.

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KNOWNASPRATYUSH/INDIA-FITNESS.git
   cd INDIA-FITNESS
   ```

2. **Serve locally:**
   Run any local static server:
   ```bash
   # Using Python
   python -m http.server 8080

   # Or using Node / npx
   npx serve .
   ```

3. **Access in browser:**
   Navigate to `http://localhost:8080`.
